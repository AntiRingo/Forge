# 炉火与锋刃 · 3D 锻剑工坊

使用 Three.js 制作的单人网页锻剑游戏。场景、剑形、火焰和粒子均由真实 3D 几何体实时渲染。

## 本地游玩

安装 Node.js 22 或更新版本。在本目录执行：

```sh
npm install
npm run build
npm start
```

打开 http://127.0.0.1:5173。已生成的 dist 目录也可直接部署到任意静态网站服务器，无需后端。不能通过 file:// 双击 HTML 运行 ES Modules。

## 操作

- 拖动场景旋转，滚轮缩放，点击“重置视角”恢复镜头。
- 初始 180 金币、4 份普通赤铁矿。
- 选择矿石、品位、剑形和熔炼方式，入炉消耗材料。
- 调节风量，让温度保持在绿色区间；进度到 100% 后浇铸。
- 点击挥锤，或在锻造场景中按空格。指针接近中心时品质增益更高。
- 至少 3 锤可淬火。每一锤前显示下一锤的实际断裂概率。
- 可选择油淬（韧性）、水淬（硬度）或风冷（锋利），然后售卖或收藏。
- 商会免费采矿有 3.5 秒冷却，资金为零也可继续。
- 音效默认关闭，可通过右上角音符开启。
- 存档存于当前浏览器，可导出和导入；切换浏览器或网址时需手动迁移。

## 内容与规则

6 种矿石 × 3 种品位；5 种剑形；3 种熔炼方式；3 种淬火方式；
5 级熔炉与 5 级铁砧；成剑收藏、售价统计、资金循环和废料回收。

游戏使用适合游玩的简化冶金规则，矿石属性、熔点与合金为游戏设定。参考视频未能直接读取，本版本根据需求独立制作，不包含原作素材。

基础属性由矿石决定，并乘以品位、剑形、熔炼方法、剑坯纯净度、最终品质与淬火方式系数。重量受剑形、材料密度、精炼和锻打次数影响。售价综合材料价值、形制、品质、硬度、锋利、韧性和相对重量；公式集中在 dist/game.js。

前 5 + 铁砧等级索引 × 2 次锻打安全。之后每一锤的断裂率随次数递增，受材料韧性和熔炼品质影响。断裂时材料报废，可回收少量金币。品质最高为 100，再锻无额外增益。

熔炼在可见浏览器标签中推进；切换到矿石商会仍会推进。后台标签暂停计时。完成熔炼后等待浇铸不会继续损失纯净度。

## 验证

```sh
npm test
node scripts/playtest.mjs
```

浏览器测试需要本机 Microsoft Edge 与已运行的本地服务器，使用独立临时会话，不修改真实玩家进度。截图和结果保存在被 Git 忽略的 qa/。

11 项规则测试覆盖售卖防重复结算、炉温锁定、材料消耗、风险递增、断裂回收、铁砧升级、免费采矿、属性关联、存档校验、温控损耗，以及所有 30 种材料/剑形组合。
浏览器流程覆盖 WebGL 初始化、熔炼、锻打、刷新恢复、淬火、收藏、售卖、购买、指南和手机布局。

浏览器原生 WebMCP 支持可用时，提供只读工坊状态和免费采矿工具；当前测试浏览器不支持该接口，原生工具注册验证不可用，不影响正常游玩。

## 文件

- dist/index.html / style.css：完整游戏界面
- dist/game.js：独立规则、经济与存档校验
- dist/scene.js：场景、实时灯光、剑身建模、火焰与粒子
- dist/app.js：交互、自动保存、音效与帧循环
- dist/vendor/：Three.js 及 MIT 许可，本地自带
- server.mjs：本地静态服务器
