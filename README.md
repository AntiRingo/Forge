# 炉火与锋刃 · 第一人称锻造工房

可自由行走的工房与庭院，实体操作完成订矿、搬筐、进气控温、开闸铸型、夹坯、时机锻打、淬火、出售和墙面藏剑。生产没有菜单按钮，也没有物体上方的悬浮标题。

## 运行

Node.js 22 或更新版本：

```sh
npm install
npm run build
npm start
```

打开 http://127.0.0.1:5173 。`dist` 可部署到静态 HTTP 服务器，Three.js 本地自带；不要直接通过 `file://` 打开 HTML。

## 操作与五格物品栏

- WASD 移动，鼠标环顾，Shift 快走；抱矿筐时减速。
- 左键拿取或操作，右键放下当前物品，交互距离 2.8 米。
- 滚轮或数字 1–5 切换五个格子；切到空格即空手。
- 物品栏可放锻锤、夹钳、单块矿石、冷却后的成剑或断剑。每件独占一格，不堆叠。拿取时使用空格，满栏会拒绝拿取，不扣矿筐库存、不丢物品。
- **热剑坯不能收入物品栏。** 必须先装备夹钳，再左键夹起；夹持热剑时不能切换格子，需右键放到铁砧或地面。冷却后切换格子可收起成剑，满栏时需先放下、悬挂或出售。
- 整筐矿石也不进入物品栏。抱筐时暂停切换，右键放下后恢复原装备。
- ESC 暂停，H 收起手札，M 音效，F 全屏。鼠标锁定受限时方向键可环顾。

物品栏格子、选择位置、库存和夹钳所持热剑都自动保存。游戏需要键盘与鼠标。

## 开局、订矿与睡眠

开局 360 金币、0 炉印，床边赠送一筐已入库的赤铁矿（4 块）。已入库矿筐左键取一块入栏，Shift + 左键抱整筐；空筐可直接拿起。

院外左侧订矿桌有六种矿样，瞄准查看属性，空手左键下单。每筐 4 块，立即扣款，次日配送到院外货区。必须亲手把整筐搬入工房放下才能取矿，搬回院外则重新成为未入库。现货加在途最多 18 筐，空筐可在废料箱回收。

| 矿石 | 一筐价格 | 熔点 | 基础锋利 | 基础硬度 | 基础韧性 | 密度系数 |
|---|---:|---:|---:|---:|---:|---:|
| 赤铁矿 | 72 | 1080°C | 35 | 39 | 51 | 1.00 |
| 青铜矿 | 128 | 1170°C | 43 | 46 | 47 | 1.08 |
| 精钢矿 | 260 | 1400°C | 58 | 60 | 57 | 1.02 |
| 曜晶矿 | 520 | 1670°C | 80 | 73 | 39 | 0.90 |
| 秘银矿 | 1000 | 1990°C | 75 | 67 | 87 | 0.62 |
| 陨星矿 | 1840 | 2380°C | 90 | 88 | 83 | 1.15 |

以上为游戏数值。矿种有不同颜色、晶体及纹理。一天为 6 分钟有效游玩时间，显示 08:00–20:00，之后进入次日。空手到床边按住左键 2 秒可休息，播放夜幕到晨光过场并推进一天。暂停、后台与离线不推进时间；睡眠会推进国王订单周期。

## 进气旋钮、混合配矿、模具与并行生产

1. 后墙提供骑士长剑、双手巨剑、贵族细剑、弧刃长刀、猎人阔刃五种模具，左键选择。长剑和细剑耗 1 块矿，其余耗 2 块。
2. 从矿筐取矿入栏，装备矿石后右键投入炉口。同炉可以混合不同矿种，容量为 2 份矿石当量；加入固体会重新计算熔化进度。
3. 熔炉左侧为**进气旋钮**，旋钮上方没有告示牌。空手按住左键左右拖动旋转，右增左减，进气范围 0–100%。50% 保温，高于中位持续升温，低于中位持续降温；松手后仍保持进气设置，可离开加工其他剑。
4. 进气控制升降温速度，不再对应固定目标温度。50–100% 的升温速度为每秒 `1.7 × (进气百分数 − 50)` °C，0–50% 的降温速度为每秒 `0.7 × (50 − 进气百分数)` °C；炉温范围 450–2650°C。HUD 显示进气量、当前温度、实际升降温速度、矿种占比和配料基础属性。混合料必须达到其中最高的矿石熔点才能完成熔化；该熔点至 +100°C 为理想温区。
5. **铁水实际流出前均可换模具**，包括投料后和完全熔化后。流入模具后锁定本次剑形，关阀暂停不会解锁。
6. 熔化且用量足够时，空手左键开阀，铁水沿流槽自动铸型，注满自动关闭。中途关阀保留进度。用 2 份金属铸单份剑形时，余料按相同比例保留在炉内，可继续铸下一把，也可以添入另一种矿石重熔。
7. 热剑坯用夹钳夹起，搬到铁砧右键放下，再滚轮切换锻锤。

每把剑独立保存矿石配比、剑形、属性、位置、锤数和冷却进度。熔炉、模具、铁砧、水槽和售卖各自工作，上一把未完成也能造下一把。模具与铁砧各容纳一把，热坯可放地面暂存；最多同时保留 48 把剑刃。

## 锻打、冷却、出售与展示

装备锻锤，对准铁砧或砧上的剑坯，在时机条金色中心附近左键落锤。不分部位，每次成功落锤提升品质，准确时收益更高；挥锤间隔 0.42 秒。前 5 锤安全，此后断裂风险升高，受矿种、模具韧性及纯净度影响。至少 3 锤可淬火，断剑可拿到废料箱回收，不妨碍其他工位。

矿石决定基础锋利、硬度、韧性、密度与价值；混合料按各矿石当量占比加权计算这些数据，颜色也随配比变化。例如秘银减重并提高韧性，曜晶提高锋利度但降低韧性。铸出的剑保留独立配比，之后给熔炉添料不会修改已有剑坯；模具影响形状、用料、重量和各属性倍率；温控决定纯净度；锻打提高锋利、硬度并降低重量，过量会损伤韧性。品质与售价综合这些数据，HUD 实时显示数值、锤数和下一锤风险。

用夹钳搬剑到水槽，按住左键浸水，中断可继续。冷却成剑后：

- 可收入物品栏，通过滚轮切换手持。
- 可放到入口右侧原售卖台，右键出售，获得**金币和 1 枚炉印**。
- 可放到工房左侧没有窗户的实墙挂架，右键竖直悬挂、左键取回。三个独立挂位不设告示牌，不可覆盖，不产生出售收益。

抽奖机保留实体外观、球仓、铭牌和摇杆动画。奖池与规则待后续设计，当前不消耗炉印。

## 自动国王订单

只保留国王订单，**没有普通订单、公告板或交单窗口**。左上角自动显示当前敕令，不需要接取或手动交付。

王令指定矿种时要求使用该种纯矿料，混合料不会冒充其中的单一矿种。首单要求纯赤铁矿骑士长剑，品质至少 32，周期覆盖第 1～7 天。锻造出的剑在**完全冷却成为成剑后自动核验**矿种、剑形、品质及属性，符合即计入任务。任务不消耗剑，剑仍可出售、收纳或展示。同一把剑最多计入一张王令，重复拿放、刷新或再次冷却不会重复奖励。

多把要求可分次完成。整单完成时获得 `100 + 王令级别 × 80` 金币赏金，以及与要求数量相同的炉印；出售剑时仍独立获得金币和 1 炉印。

**提前完成也不会立刻发下一单。** 第 1 单完成后等待到第 8 天才自动发第 2 单，第 2 单覆盖第 8～14 天，依此类推。每期固定 7 天，逐步提高矿种、品质、锋利/硬度/韧性与数量。完成期间显示下一单的发布日期。

期限结束时仍未完成会经营失败，冻结操作，失败状态会保存。失败界面的“从头开始”重置到第 1 天，恢复初始资金、空物品栏、一筐赤铁矿和首单周期。睡眠同样受期限约束。

## 存档与验证

保存键 `ember-edge-workshop-v6`，保存五格库存、装备位置、热坯夹持、独立剑刃与墙面展示、炉内余料及配比、进气量、日期、货运、金币/炉印及王令周期、自动计数和失败状态。

兼容 v5、v4、v3、v2 第一人称旧存档。v5 迁移保留王令周期、进度和已发奖励，将单矿配方转换为成分数据，已挂成剑随挂架移至实墙；原风力代表目标温度，迁移时改为中位保温以保留当前炉温。v4 及更早存档，保留资产与在制品，原手持工具或冷却剑迁入物品栏，热坯继续由夹钳夹持；移除普通委托，迁移时从当前日期起给予新的七天王令周期。旧存档键不删除。

配料结构为每种矿石的当量与比例；同时预留空的辅料字段。当前不提供辅料种类、获取方式、配方或效果。

```sh
npm test
node scripts/playtest.mjs
node scripts/playtest-orders.mjs
node scripts/playtest-materials.mjs
```

44 项规则测试（33 项当前工房规则，11 项保留旧规则），覆盖 30 种纯矿剑形配方、21 组双矿组合、不同配料的属性与风险、部分浇铸和余料配比守恒、进气升降温、物品栏、热剑禁收、独立生产、挂墙、王令自动核验、40 期周期、奖励防重复及迁移。

浏览器测试需要 Microsoft Edge 与本地服务器。第一条浏览器脚本从新局完成订矿、睡眠、搬筐、旋钮控温、锻造、淬火、挂墙取回和出售。第二条在独立测试存档中验证五格容量、滚轮/数字切换、热剑禁收、自动完成任务、第八天新单、失败重开和 800 × 600 布局。第三条通过实际鼠标操作验证混矿入炉、配比 HUD、持续升降温、保温、部分浇铸重载与混合剑坯。截图及结果保存在忽略目录 `qa/`，不影响玩家存档。

## 文件

- `dist/workshop.js`：生产、库存、进气、配料、属性、王令周期、资金和存档。
- `dist/scene.js`：地图、实体工位、矿种/剑形、挂架、碰撞、手持与动画。
- `dist/app.js`：键鼠与滚轮、只读 HUD、物品栏、过场、音效与自动保存。
- `dist/index.html` / `dist/style.css`：启动、暂停、失败界面及 HUD。
- `dist/game.js`：共享材料和剑形配置、保留旧规则。
- `server.mjs`：本地静态服务器。
